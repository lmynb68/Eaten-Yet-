## 使用

现有应用可复制 assets/official.json 全文（菜单版本7），在“导入官方库”中粘贴，先校验再确认替换；导入后在“管理官方店铺”选择风味餐厅。自定义官方库用户应先导出备份，官方库导入属于整库替换，个人库独立保留。

需要新安装包时运行 build-android-release.cmd；该脚本会先执行分析和测试再构建。当前不能声称新包已通过验证。
