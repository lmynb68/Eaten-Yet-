# v0.12.0：同店选餐、喜爱记录与偏好加权

## 使用变化

- 官方米饭选菜仅食味坊提供；社区食堂和牛肉面店没有入口。个人手工菜单仍保留，但不能给这两家官方店绑定米饭入口。
- “米饭套餐”改为“米饭选菜”，唯一菜单自动打开，不再先选套餐。多个个人菜单时才显示菜单来源切换。
- 已选主菜后切到“小食”保留当前主菜，候选小食和总价限定同店；米饭选菜也遵循此规则。
- 要单独购买小食，点“只买小食（结束当前搭配）”，再筛选店铺。更换主菜店铺时原小食清空。
- 新增“我的喜爱”。结果页的“满意，收藏这一顿”保存主菜、小食、米饭费用、店铺、照片及当时价格和时间；支持删除。
- 重复收藏相同组合更新记录，不重复累加权重。删除记录同时撤销该条记录的加权影响。
- “根据喜爱调整推荐”默认开启，可随时关闭。关闭后仍保留收藏，按当前预算、锁定及去重条件等概率随机。
- 数据与算法均在本机运行，不上传、不汇总其他人的偏好。收藏使用独立存储项，不影响官方菜单、个人菜单或店铺安装状态。

## 算法

初始单菜权重和菜对系数均为1。一个食物在不同喜爱组合中每出现一次，权重增加0.25，上限3；一对食物每同时出现一次，系数增加0.15，上限2。

组合得分 = 单菜权重的几何平均 × 菜对系数的几何平均；最多6倍，不排除未收藏的食物。用加权抽样选择合规组合。食物按来源、店铺/窗口及菜品身份区分，不向其他店的同名菜传播偏好。计数预先索引，避免每次枚举米饭组合时遍历全部收藏。

预算、同店、锁定和不重复优先于权重。既有“换一份”语义保留：有其他候选时不立即返回上一份；米饭不会仅交换菜位来假装新组合。
