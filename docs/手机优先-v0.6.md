# v0.6 手机优先与店铺导航

项目主要平台调整为Android和iOS（iPhone），Windows作为辅助测试平台保留。

## 已修改

- 首页移除“包含抖音团购价”开关；整份随机和手选沿用此前默认的非团购记录，不悄悄启用有核销条件的价格。
- 结果卡片只显示菜名、店铺、窗口、价格，去掉“普通标价”。详情也不再显示这个词。
- 团购记录保留在餐品菜单和店铺菜单，仍注明团购，便于区分不同购买条件。
- 新增“店铺”导航，位于“餐品菜单”之后、“菜单库”之前。展示所选菜单库内所有店铺，包括暂未录入菜品的店铺。
- 点击店铺查看按placeId关联的售卖项，再点击餐品查看详情。官方库和个人库采用独立来源，不把同编号店铺错误合并。
- 食味坊保留窗口归属，199条记录；金面郎29条。仅修改界面，未清空个人数据。

## iPhone

现有Dart界面、套餐逻辑和数据库代码继续共用；当前Windows工作区没有已生成的ios工程，也没有IPA。
新增prepare-ios.sh，在安装Flutter和Xcode的Mac上执行：

```bash
bash prepare-ios.sh
flutter build ios --simulator
```

脚本在临时项目中用官方Flutter模板生成ios运行工程，再复制ios目录，保留现有业务源码。首次需要下载依赖。真实iPhone安装需要在Xcode打开ios/Runner.xcworkspace设置签名团队与应用标识；应用图标、签名及真机验证仍需在Mac完成。脚本尚未在Mac执行，不能视为iOS已构建。

## Android 构建与验证

源码版本0.6.0+6。手机导航测试新增检查：没有团购开关、没有普通标价、店铺2家、分别199/29条关联、店内餐品详情。
静态检查确认228条数据保持不变，按店铺ID分组正确，首页旧控件已移除。
当前代理环境重新启动Flutter仍报resolved_executable_name错误，v0.6测试和APK尚未生成。此前v0.5的28项测试与APK成功记录不代表v0.6已经通过。

在用户电脑双击build-android.cmd重新运行分析、测试、构建，成功后输出outputs/eat-what-android-debug.apk。目前已有的同名APK还是v0.5，不要将它当作新版。使用相同包名和签名覆盖安装可保留本机数据，请勿先卸载。
