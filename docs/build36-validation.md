# build36 修复与验收范围

候选版本：`1.0.1+36`。本轮以 build35 候选分支为基础修复六项审计遗漏。已发布版本的下载入口保持不变；正式签名候选包和远端 CI 的最终状态以交付目录 `build-info.json` 为准。

## 修复内容

- 个人米饭套餐按菜单范围筛选时，仍可解析它引用的官方店铺；关联店铺退出官方菜单后不会继续当作可用店铺。
- 评价框与历史存储统一按用户可见字符计数，最多 2,000 个字符。保存失败时保留文字和星级，保存成功后才关闭弹窗，防止重复提交。
- 菜单重建增加图片编码、分类等检查，并在替换正式菜单前用真实 `MenuDb.decode()` 验证候选文件。CI 同时运行 Python 用例和 Dart 解码往返检查。
- 菜单、用餐历史和恢复资料可通过 Android 系统文件选择器保存；菜单与历史可从文件导入。大备份不再依赖剪贴板。原生桥仅传递私有缓存文件路径，文件内容以流方式读写；取消、失败及正常完成后清理本次临时文件。
- 历史恢复使用与收藏一致的安全编码方式，异常存储值为非有限小数时也能保留原始信息。
- 在线依赖恢复同样使用 `--enforce-lockfile`，与离线模式和 CI 保持一致。
