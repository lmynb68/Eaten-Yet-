# 百特快客（传统中餐）核对

新增44个售卖规格。照片1门头、2价目表、3熟食、4补充包点。

按独立门头区分中西餐；旧西餐ID btk不变，中餐ID btz。两店是否统一管理未作判断。

- 油条：一根0.8元、一对1.5元；小笼包一笼9元，不推算数量。
- 鸡爪46元/斤、鸡胗20元/斤、猪耳朵50元/斤不参与整份随机。
- 土豆烧肉包与烧肉土豆包3元按同款合并；玉米火腿包、鱼香肉丝包、豆角烧肉包重复牌只计一次。
- 包点按单件录入；价目表没有逐项印单位，此处为按品类理解。粥与老豆腐份量未注明。
- 展示牛奶无清晰售价，不录入。

## 已关闭事项（2026-10-22）
- 用户要求包点单位、份量、小笼包数量及展示奶售价不再追查；保留现有录入，不补猜数量或价格。
