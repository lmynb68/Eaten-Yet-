# 吃了么官网设计规则

## 方向

以“校园日常的克制编辑感”为核心：真实 Android 界面是主要视觉，排版与留白负责建立质感，不用装饰性卡片堆叠、渐变或炫技动画。

## 颜色

- 页面纸色：`#FAF7F2`
- 次级纸色：`#F1ECE4`
- 主要文字：`#1C1A17`
- 次级文字：`#655F57`
- 分隔线：`#D9D0C5`
- 陶土橙：`#C0512F`，仅用于主行动、焦点和关键状态
- 陶土深色：`#8F351E`

## 字体与层级

- 中文展示标题使用系统宋体优先：`Songti SC / STSong / Noto Serif CJK SC`。
- 正文使用本机中文无衬线系统字体，不加载远程字体。
- 首页主标题使用响应式字号；正文不小于 `16px`，行高约 `1.7`。
- 信息层级主要依赖字号、字重、留白和对齐，不依赖阴影或边框装饰。

## 布局

- 内容最大宽度 `1200px`，桌面端使用不对称双栏；移动端按自然阅读顺序重排。
- 间距以 4/8 的倍数为主，主要区块间距为 `72–144px`。
- 断点重点覆盖 `320 / 360 / 390 / 768 / 1440px`。
- 手机端截图画廊只显示一张主图，通过横向可滚动标签切换其余截图。

## 图片

- 仅使用 `assets/` 内真实项目素材。
- 五张截图原始比例均为 `1080×2376`，页面预览统一裁切顶部状态栏；原图文件不修改。
- 所有图片保留 `width`、`height` 属性，非首屏截图由切换后按需加载。

## 交互与无障碍

- 键盘焦点使用 3px 陶土橙轮廓。
- 移动菜单支持关闭、链接后自动收起和 `Escape` 返回。
- 截图标签支持方向键、Home、End。
- 下载数据读取 `release.json`；静态 HTML 保留与其一致的降级链接和校验值。
- 复制失败时保留可选择的明文发布页链接。
- 遵循 `prefers-reduced-motion`，不使用非必要动画。

## 官网第二版接入
Open Design 生成新版首页、共享样式、交互、安装与隐私页。仅接入明确的公开网页文件；未带入 Open Design 内部历史、压缩包或工作路径。
接入复核：发布元数据与原版完全一致，6 张素材逐文件 SHA-256 一致；3 页资源/锚点、JavaScript 语法及公开范围检查通过。补回 canonical / Open Graph，修正 MiB 单位及安装页旧措辞。
新版浏览器脚本已适配菜单、复制及截图切换。旧版 10 项浏览器通过记录不能代替新版验证；新版动态复核结果见下方，线上部署以 GitHub Actions 为准。

## 接入后的浏览器验证
用户在本机运行新版脚本后，已读取结果：12 项检查全部通过，覆盖 320/360/390/768px 无横向溢出、菜单开合、复制成功与拒绝处理、截图点击与 End 键切换、模拟弱网加载及交互。400ms 延迟、50KB/s 下本地页面就绪约 8.9 秒，不能作为线上速度承诺。
真实手机浏览器和系统剪贴板权限未实测；桌面 1440px 预览由 Open Design 阶段报告，未计入本次 12 项检查。
