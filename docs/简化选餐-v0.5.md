本次已修改源码，取消配料相关界面；旧数据中的原料字段只为兼容已有备份保留，不再参与当前界面筛选、选择或维护。

## 使用

- 普通餐品：输入预算，在“随机一份”和“自己选一份”之间选择；按整份商品价格计费，不自动配小食、饮品。
- 打开“米饭套餐选菜”：选一个套餐，三个菜位可手动选择或随机；点锁后保留对应菜位，只更换未锁定项。
- 不重复选择同一道菜，套餐总价超过预算时停止选择。无法找到新组合时保留旧结果。
- 官方自选套餐现有三种：食味坊1号窗口，大荤+大荤+小荤14元，大荤+小荤+素菜11元，小荤+小荤+素菜9元，均按完整套餐标价含米饭。
- 照片未列出每天实际可选成品菜，因此官方菜位为空。点击“复制到个人库并补充菜名”，填入同窗口实际可选菜即可使用；也可以新建个人套餐。
- 个人套餐只需名称、位置、整套价格和三个菜位的可选成品菜。固定价规则只适用于所列菜都无需另加价的套餐；加价菜应另建套餐。
- 官方库和个人库分别导入导出。新版 schemaVersion 3 / revision 3；兼容读取旧schema1/2。个人数据不会因官方更新被覆盖。
- 若本机已保存旧真实官方库，仍会保留它。可导入 outputs/menu-data/官方菜单-v3.json 更新；原始演示库自动升级。
