# build35 修复与验收范围

候选版本：`1.0.1+35`。build34 安装包保留，本轮修复必须用新包验收。此文记录源码检查，正式包和远端 CI 结果以交付目录的 `build-info.json` 为准。

## 修复内容

- 菜单重建补齐麦港餐厅的可重复录入，保留第 10 版、10 家店、1,735 项菜品，其中麦港 101 项。候选文件先在隔离目录生成；禁止降版、遗漏或擅改已有记录，通过校验后才原子替换。
- 收藏恢复支持非字符串原值（包括非有限小数），并固定本次恢复原文；备份写入失败后必须重新持久化，第二次独立损坏保留另一份副本。反序列化与保存统一拒绝负价格、无效数量和缺失字段。
- 餐次配置读取异常回退默认值，用户可从设置页重新保存；历史列表改为按需构造，避免一次生成 2,000 张卡片。
- 源码归档读取 Git 原始字节和权限，拒绝强制跟踪的 `.env` 及其变体；Linux CI 从归档解压目录实际构建。
- 延续已修复的 CI 依赖来源配置，保留 `--enforce-lockfile`，本地与 CI 使用 Flutter 3.47.8。

- Dart 静态分析：退出码 0，无诊断。
- Flutter 完整回归：169 项通过，退出码 0。
- 发布脚本：10 项通过。
- 源码归档：Windows 8 项通过，1 项 Linux 原生解压执行检查留给 CI。
- 菜单重建：13 项通过；实际目录 `--check` 通过，正式菜单文件未改变。

本地日志位于检出目录外：`build35-final-analysis.log`、`build35-final-tests.log`、`build35-supporting-verified.log`。首次受限环境的归档测试因临时目录访问被拒失败；在允许访问的环境重跑通过，原失败记录保留在 `build35-supporting.log`。
