# v0.13.0 手机排版调整

基于已确认的 Open Design 预览方案调整正式 Flutter 页面。

- 首页：预算独立白底区域，模式横向排列，筛选摘要取代多行主食按钮，随机操作放在结果上方。
- 菜单：搜索前置，餐品分类为单行横向标签，保留懒加载列表。
- 筛选：店铺、主食与菜单来源集中到底部面板；两列等宽选项适应长中文店名，关闭取消草稿，应用才生效。重置同时清除主餐勾选限制。
- 原有逐项勾选主餐功能在筛选面板内保留。同店小食、预算约束、收藏与加权逻辑保留。
- 全局：中性浅灰背景、暖棕强调色、统一圆角与间距，白色底部导航。
