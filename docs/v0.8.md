# v0.8：设置、可选小食与照片

- 首页显示“数据来自10月15日”；这只是展示文案，不修改照片原始采集日期。
- 右上角设置可切换简体中文 / English，语言选择保存在本机。菜名、店名、个人内容保留原文。
- 整份餐品、米饭套餐可以额外选择一份小食，也可不选；合计使用同一预算。切换分类或菜单库会清空选择。降低预算后保留结果并显示超预算提示。
- 添加个人菜品采用全屏滚动表单，字段间距20像素，保存和取消固定在底部。
- 可从相册选图、更换或移除；照片内嵌在个人数据中，随导出迁移。单图上限300KB、图片总量上限10MB。选择时请求缩小到900像素并压缩，过大的图片会提示重新选择。
- 餐品结果、手选列表、菜单、店铺菜品、个人列表和详情展示照片或占位图；米饭套餐预留展示位。
