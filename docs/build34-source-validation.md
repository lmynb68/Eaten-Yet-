# build34 源码与归档验收

版本：1.0.1+34。build33 的 APK 和源码 ZIP 保留不变，不能用于验收本轮文案改动。

## 本轮修改

- 统一“菜单管理”等用户界面用语，补齐导入、份数、店铺位置等英文，清理未引用的旧翻译。
- 更新页按十进制 MB 显示实际下载大小；修正网站介绍和安装说明。
- 新增从干净 Git 提交归档的脚本，清单覆盖归档内全部文件；排除生成物不是靠静默跳过，而是发现误跟踪时拒绝归档。
- 移除网站目录中已无引用的旧 APK；历史 build33 另外补充完整文件清单。

## 本地结果

- Dart 静态分析无诊断，退出码 0。
- Flutter 完整回归 143 项通过；清理旧翻译后，文案、历史份数、选餐交互专项 13 项通过。
- 发布脚本测试 10 项、源码归档测试 4 项通过。
- 网站 3 个 HTML 页面、资源、锚点、脚本语法和发布元数据检查通过。
- PowerShell 语法检查通过。

日志保存在检出目录之外的工作目录，分别为 `build34-analysis.log`、`build34-tests.log`、`build34-copy-tests.log`、`build34-release-script-tests.log`、`build34-archive-tests.log`、`build34-site-check.log`。

正式包如完成构建，以交付目录的 `build-info.json`、`SHA256SUMS` 和源码完整清单为准，不以本文件替代验包证据。源代码归档流程见 [source-archive.md](source-archive.md)。

## 验证边界

本轮没有手机覆盖安装、数据保留、历史评分流程、手机性能或完整 Android E2E 的验收结果；本地通过不等于远端 CI 已运行。官网继续保留已公开版本，待候选包验收并发布后统一切换元数据与无 JavaScript 兜底链接。
