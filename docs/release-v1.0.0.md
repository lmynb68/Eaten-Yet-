# 吃了么 · 第一代正式版 v1.0.0

正式应用名称：吃了么（Eaten Yet?）；Android 版本号1.0.0，构建号23。
保留包名local.eatwhat.campus与既有本机签名，以支持覆盖升级。

- 9家店铺，1666个售卖项（1634个规格与32项米饭配菜）。
- 风味餐厅、钟小北菜单；钟小北店铺照片；已核对的菜名、价格和规格。
- 按预算选餐、同店搭配、米饭锁定重抽、收藏及独立个人菜单。
- Android实机截图官网，微信内下载指引。
