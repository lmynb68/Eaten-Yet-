# 吃了么 · 1.0 正式版

版本 **1.0.0+25**；Android 包名 `local.eatwhat.campus`，支持 Android 7.0（API 24）及以上。2026-10-26 发布。

提供预算选餐、同店搭配、米饭锁定重抽、收藏、个人菜单与应用内更新。旧版没有下载器，需先手动升级一次；后续在应用内下载更新并由系统确认安装。

相同专用正式签名可以覆盖升级；旧 debug 测试签名须先备份再迁移。菜单导出不包含完整收藏与设置。
