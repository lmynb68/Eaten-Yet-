# 应用内更新（1.0.1 开发记录）

状态：2026-10-26 正式版 1.0.0+25 与临时测试版 1.0.1+26 均通过静态分析和 96 项测试，正式签名安装包已发布并核对附件校验值。用户随后确认应用内升级功能测试成功；官网默认下载正式版 1.0.0+25。

用户路径：设置进入应用更新 → 检查更新 → 查看更新说明和包大小 → 下载并安装更新 → 应用内显示进度 → 完整性与身份校验 → 系统安装确认。首次可能进入“允许此来源安装应用”授权页，返回后点击继续安装。取消系统安装不会被当成升级成功。

- 仅选择本仓库稳定 Release、已上传且提供 SHA-256 digest 的安装包；ARM64 设备优先 ARM64，其他设备使用通用版。缺少校验值不降级为无校验安装。
- 仅允许 HTTPS GitHub 与其指定资产存储域名跳转。网络停滞 30 秒失败，可重新下载；不提供后台下载或断点续传。
- 下载到私有缓存，限制大小，取消或传输异常清理部分文件。校验大小、SHA-256、包名、签名与递增 versionCode；系统最终验证签名和安装兼容性。
- 不请求公共存储读写权限。FileProvider 只开放 updates 缓存目录，只给安装器临时读权限。
- 不卸载旧版、不清空菜单/收藏/设置。不符合签名的旧测试版不能直接覆盖。
- GitHub 下载源的国内可达性尚未改变。镜像须另外配置，不能将本改动描述为国内网络问题已解决。
- 旧 1.0.0 没有下载器，需手动安装一次新正式包；之后才具备应用内更新能力。
