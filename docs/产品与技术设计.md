# 产品与技术概览

吃了么是本地优先的 Android 选餐工具；官网是介绍与下载入口，不提供在线选餐。

- 预算内选择主餐，搭配同店小食，支持米饭选菜锁定与重抽。
- 官方菜单与个人菜单独立保存，可单独使用或合并推荐。
- 收藏与推荐偏好保存在本机，用户可关闭偏好学习。
- 菜单导出用于所选菜单库迁移，不包含完整收藏和设置。
- 官方菜单与应用更新由用户主动检查；安装包在应用内下载并校验，由安卓系统请求安装确认。

Flutter 应用位于 `lib/`，安卓原生安装桥接位于 `android/`。静态官网位于 `site/`，菜单及公开素材位于 `assets/`。

当前版本与验证结果见 [发布验收](release-checklist.md)，更新机制见 [应用内更新](in-app-update.md)，网站视觉规范见 [设计说明](site-design-v2.md)。历史设计迭代保存在 Git 历史中，不再作为当前使用说明。
