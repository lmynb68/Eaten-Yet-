## 安装前置组件

打开 Android Studio 的 SDK Manager：
- SDK Platforms：Android SDK Platform 36。
- SDK Tools：Android SDK Command-line Tools (latest)。
- SDK Tools中勾选Show Package Details，选择NDK (Side by side) 28.2.13676358。

已有Build-Tools36.0.0和Platform-Tools，不需要重复安装。以上版本来自当前Flutter SDK的FlutterExtension.kt。检查以android/local.properties中的实际SDK为准。

安装后双击check-android.cmd核对，再双击build-android.cmd。首次Gradle构建需要访问下载服务器，Flutter依赖使用已有离线缓存。若出现许可证提示，在Flutter终端运行flutter doctor --android-licenses并自行审阅接受。

成功后会自动复制安装包到项目outputs/eat-what-android-debug.apk并输出SHA256。将APK发送到安卓手机，点击安装并按手机提示允许此来源安装。该包为调试签名测试包，不是应用商店正式发布包。最低Android版本由当前Flutter设置为API24（Android7.0）。
