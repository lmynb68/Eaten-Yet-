# Android 构建

1. 安装 Flutter，设置 `FLUTTER_ROOT` 为 SDK 根目录；准备 Android SDK 和 Java。当前已验证 Flutter 3.47.7 / Dart 3.13.5，CI 使用 JDK 21。
2. 用 `run.ps1 -Target doctor` 或 `flutter doctor -v` 检查环境，按提示安装 SDK 组件。所需 compile SDK 和 NDK 以当前 Flutter / Gradle 配置为准，不依赖旧版硬编码检查脚本。
3. 运行 `check.cmd` 进行分析与测试；`build-android.cmd` 生成调试包，不能作为正式交付。
4. 正式版配置本地 `android/key.properties`（storeFile、storePassword、keyAlias、keyPassword），运行 `build-android-release.cmd`。私钥与密码禁止提交。

日志位于 `logs/`。正式文件在仓库上一级，名称包含 pubspec 中的版本与构建号，分别以 `-android-arm64.apk` 和 `-android-universal.apk` 结尾。脚本校验正式签名、包名、版本和非调试标记，并输出 SHA-256。

若出现 `resolved_executable_name` 启动错误，请在本机终端运行相同脚本；旧构建日志不能代表新源码验证成功。

调试证书与正式证书不同，不能直接覆盖安装。相同正式签名且内部构建号递增时可覆盖升级；不要为了升级先卸载并丢失数据。详见 [安装说明](../site/install.html) 与 [当前验收](release-checklist.md)。
