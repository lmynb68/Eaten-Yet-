# v0.9 同店小食与多选筛选

- 附加小食仅来自主餐同一店铺（来源库 + 店铺编号）；食味坊不同窗口视为同一店铺。同名但不同库的店铺不会自动合并。
- 切换至另一店铺的主餐时清除旧小食，预算计算不再扣除旧店小食。保留同店小食时仍合计检查预算。
- “筛选店铺和主餐”支持多选。店铺复选框勾选/取消该店全部主餐，展开后可逐项选择，部分选中时显示半选状态。随机、手选、米饭套餐列表均使用筛选范围。
- 清空选择表示没有可选主餐；“清除筛选”恢复不限范围。应用筛选或切换菜单库会清除当前餐品，避免结果与范围不符。筛选只作用于主餐，独立小食模式仍可使用。
- 米饭套餐新增所属店铺关联。旧套餐仅在地点唯一匹配店铺时沿用；未知或歧义地点禁用附加小食，编辑关联后可用。
