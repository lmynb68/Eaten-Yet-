Android v1.0.0

安装与旧版迁移

第一代正式版 v1.0.0 已发布，支持 Android 7.0 及以上。

选择安装包

ARM64 包面向支持 arm64-v8a 的设备，通用包包含多种处理器架构。支持 Android 7.0 及以上，文件大小和校验值见首页下载区。APK 不能安装在 iPhone 上。

旧版迁移：请先备份

正式版采用专用签名，与旧版测试证书不同；即使包名相同，也不能直接覆盖安装。

  1. 在旧版“菜单库”导出个人库，将 JSON 内容保存为 UTF-8 文件，并检查内容完整。若自行导入过官方库，也单独导出。
  2. 现有菜单库导出不包含完整收藏、学习偏好及所有设置。请另外记录需要保留的收藏和设置；不要在尚未备份时卸载。
  3. 确认备份可读后，卸载旧版，安装新包，再导入个人库。导入前先校验，确认替换的库。

安装与反馈

仅从项目发布页获取安装包。下载后核对 SHA-256，再按系统提示允许所用下载来源安装应用；不要关闭系统整体安全保护。若提示签名冲突，按上面的迁移流程处理。

反馈请提供应用版本、Android 版本、设备型号、复现步骤与错误提示；截图先遮住个人菜单、联系方式等私人内容。不要提交备份文件、密钥或密码。
