菜单和收藏保存在手机里

菜单、你添加的照片、收藏、推荐偏好和设置均保存在应用本地。吃了么不提供账号登录或云端同步。

什么时候会联网？

检查应用更新、获取在线菜单或下载安装包时，应用会连接 GitHub 提供的服务。这些请求不主动上传你的个人菜单、照片或收藏；服务提供方仍会接收 IP 地址、请求时间等必要的连接信息。

下载的安装包临时保存在应用缓存中，通过安全检查后由手机系统请求你确认安装。重新下载时会清理上一份缓存安装包。

备份和删除

菜单库导出仅包含选中的菜单库，不包含收藏和全部设置。备份可能含有你填写的文字和照片，请妥善保存，不要上传到公开的问题反馈页面。

卸载应用或清除应用数据会导致本地内容丢失，重新安装不会自动恢复。操作前请先保存重要菜单，并记录需要保留的收藏和设置。

访问官网

官网用于介绍和下载应用，不提供在线选餐或账号服务，也没有广告、第三方统计脚本或信息收集表单。网站由 GitHub Pages 托管，访问时的数据处理请参阅GitHub 隐私声明。
