菜单和收藏保存在手机里

菜单、你添加的照片、收藏、用餐历史（含份数、星级和评价）、推荐偏好和设置均保存在应用本地。吃了么不提供账号登录或云端同步。

什么时候会联网？

检查应用更新、获取在线菜单或下载安装包时，应用会连接 GitHub 提供的服务。这些请求不主动上传你的个人菜单、照片、收藏或用餐历史；服务提供方仍会接收 IP 地址、请求时间等必要的连接信息。

下载的安装包临时保存在应用缓存中，下载后由手机系统请求你确认安装。重新下载时会清理上一份缓存安装包。

备份和删除

菜单导出只包含你选中的菜单，不含收藏、用餐历史和设置。用餐历史可在历史页面单独导出和导入，备份包含菜品、份数、价格、用餐时间、星级和评价；复制后请私下保存。菜单文件可能包含你添加的文字和照片，请妥善保存。

卸载或清除数据会移除本机记录。换手机或重装后能否恢复，取决于 Android 系统备份；重要菜单请先导出。

访问官网

官网用于介绍和下载应用，不提供在线选餐或账号服务，也没有广告、第三方统计脚本或信息收集表单。网站由 GitHub Pages 托管，访问时的数据处理请参阅GitHub 隐私声明。
