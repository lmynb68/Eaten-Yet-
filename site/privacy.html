本地数据说明

隐私与数据说明

适用于本仓库当前应用设计，更新日期：2026-10-26。

应用在本机保存什么

官方菜单、个人菜单、个人录入的照片、收藏与推荐偏好、餐次和界面设置保存在应用本地存储中。应用不提供账号登录或云端同步。当前菜单库导出只涵盖所选菜单库，不是完整的整机数据备份。

哪些操作会联网

检查应用更新访问 api.github.com 的本项目 Releases 接口；在线菜单更新访问 raw.githubusercontent.com 的本项目官方菜单文件；1.0.1 起，主动下载应用更新时访问 github.com 及其 HTTPS 安装包存储服务（release-assets.githubusercontent.com、objects.githubusercontent.com）。安装包暂存在应用私有缓存中，仅在通过校验并由用户确认后交给系统安装器；重新下载时会清理上一份缓存包。上述请求不主动上传个人菜单或收藏；网络服务仍会接收 IP 地址、请求时间等常规连接信息。

备份、照片与删除

主动复制或导出内容后，其安全取决于你保存、粘贴或分享的位置。菜单 JSON 可能包含个人文字和照片，不要提交到公开仓库或问题反馈。卸载应用、清除应用数据可能删除本地内容；重装不会自动从本项目恢复个人数据。

官网

本网站是介绍及下载入口，不提供在线选餐或账号服务，未加入广告、第三方统计脚本或表单收集。静态网站由 GitHub Pages 托管，访问仍适用托管方的网络处理规则。公开展示图片只使用经过检查的项目素材。
